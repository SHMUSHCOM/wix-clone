# Wix Stores Re-Commerce — Buy Backs Prototype

A native buy-back / second-hand marketplace module designed as an addition to Wix Stores. This repo contains the **interactive HTML prototype** of the Wix Stores dashboard with the new Buy Backs module integrated, plus the supporting product documentation.

The prototype lets a merchant click through the full lifecycle — customer submission → merchant proposal → condition review → store-credit coupon → pre-owned relisting — entirely inside the existing dashboard shell. Buy Backs sits as a top-level sidebar pillar between Sales and Catalog, with four sub-sections: Requests, Receivables, Relisting, and Analytics.

## Running locally

Open `index.html` (prototype) or `prd-site/index.html` (PRD site) directly in a browser — no build step, no dependencies.
